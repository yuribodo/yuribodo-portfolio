A — Text com Physics (Pretext + Canvas)

O visitante literalmente brinca com seu nome. Pretext calcula o layout, Canvas renderiza, GSAP anima. Quando as letras se assentam, revelam "YURI BODO" perfeitamente alinhado. C — Game World Boot Sequence

O site "liga" como um console/OS de jogo. Pretext renderiza dados do protagonista (você) em tempo real com tipografia cinética — texto fluindo, se reorganizando, se formatando ao vivo. Um shape 3D central (icosaedro? esfera?) serve como "núcleo" ao redor do qual o texto de Pretext flui organicamente. "Press any key" → transição explosiva pro conteúdo. Mistura terminal com game boot sem ser clichê porque o texto em si é o espetáculo via Pretext.
